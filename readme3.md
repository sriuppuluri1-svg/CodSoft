# 🧮 Calculator Web Application

A simple and responsive calculator built using HTML, CSS, and JavaScript. This project performs basic arithmetic operations and provides an interactive user interface for calculations.

## 🚀 Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Clear Button (C)
- Backspace Button (⌫)
- Error Handling
- Responsive Design
- User-Friendly Interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 💡 Project Description

This calculator application allows users to perform basic mathematical calculations. The interface is designed using HTML and CSS, while JavaScript handles user interactions and calculations dynamically.

## 🎯 Objectives

- Practice HTML, CSS, and JavaScript fundamentals.
- Understand DOM manipulation.
- Implement event handling in JavaScript.
- Build an interactive web application.
